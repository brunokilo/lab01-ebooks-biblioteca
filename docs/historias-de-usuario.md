## Histórias de Usuário

### HU01, Gerenciar Senha
Como administrador do sistema, eu quero gerenciar as senhas dos usuários para ter controle dos acessos do acervo.
 - o usuário precisa estar previamente cadastrado no sistema

### HU02, Adicionar eBook a estante
Como aluno, eu quero acidionar um ebook a minha estante pare ter acesso durante o semestre.
- o usuário precisar estar logado no sistema
- o aluno precisa ter espaços na estante

### HU03, Remover eBook da estante
Como aluno, eu quero remover um ebook da minha estante pare liberar espaço para ter acesso a outros ebooks durante o semestre.

### HU04, Gerar relatório de eBook por estante
Como bibliotecario, eu quero que o sistema gere um relatório dos alunos com um determinado ebook na estante para saber quais alunos têm determinado eBook em sua estante. 
 - o usuário precisar estar logado no sistema
 - deve haver eBooks cadastrados
 - deve haver aluno com eBooks na estante

### HU05, Cadastrar disciplina
Como equipe da biblioteca, eu quero cadastrar disciplinas para atribuir os eBooks as suas respectivas disciplinas.
- o usuário precisar estar logado no sistema

### HU06, Cadastrar categoria
Como equipe da biblioteca, eu quero cadastrar categorias para atribuir os eBooks as suas respectivas categorias.
- o usuário precisar estar logado no sistema

### HU07, Alterar categoria
Como equipe da biblioteca, eu quero alterar categorias para realizar mudança na categoria dejesada quando for necessário.
 - categoria deve exixtir no sistema

### HU08, Excluir categoria
Como equipe da biblioteca, eu quero excluir categorias para naõ correr o risco de usar uma categoria que não quando é mais necessária.

### HU09, Cadastrar editora
Como equipe da biblioteca, eu quero cadastrar editoras para atribuir os eBooks as suas respectivas editoras e facilitar buscas.
- o usuário precisar estar logado no sistema

### HU10, Cadastrar ebook
Como equipe da biblioteca, eu quero cadastrar ebooks para que os alunos possam reservá-los.
 - o usuário precisar estar logado no sistema
 - deve atribuir categioria 
 - deve atribuir editora 
 - deve atribuir disciplina 

### HU11, Editar ebook
Como equipe da biblioteca, eu quero editar ebooks para realizar alterações caso sejam necessárias.
 - ebook deve estar cadastrado no sistema

### HU12, Cadastrar Aluno
